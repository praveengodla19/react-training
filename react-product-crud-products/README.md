React Product CRUD (Products model: productId, name, quantity, price)\n\nInstructions:\n1. npm install\n2. npm run dev\n3. Ensure backend API is available at http://localhost:8081/product with endpoints:\n   GET /product\n   GET /product/{productId}\n   POST /product\n   PUT /product/{productId}\n   DELETE /product/{productId}\n\nProduct JSON example:\n{ "productId": "P100", "name": "Pen", "quantity": 20, "price": 10.5 }
