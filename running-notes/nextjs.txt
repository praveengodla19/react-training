What is Next.js?

Next.js is a React framework for building fast, SEO-friendly, production-ready web applications.

Think of it as:
React + Routing + Rendering + Backend APIs + Performance


Why Next.js? (Why React Alone Is Not Enough)
Problems with plain React (CSR only)

❌ Poor SEO
❌ Slow initial page load
❌ Manual routing setup
❌ Needs separate backend for APIs

Next.js solves this by providing:

✔ Server-Side Rendering (SSR)
✔ Static Site Generation (SSG)
✔ File-based routing
✔ API routes (backend inside frontend)
✔ Image & performance optimization


Next.js vs React (Interview Table)
Feature			React			Next.js
Rendering		CSR only		CSR + SSR + SSG
Routing			React Router		File-based
SEO			Weak			Excellent
Backend APIs		External		Built-in
Performance		Good			Excellent
Production ready	Needs setup		Out of the box

Installing Next.js
------------------
Create a new project
npx create-next-app@latest my-app
cd my-app
npm run dev


Open:

http://localhost:3000
